# Central de Conteúdo — PFE Advogados

Site simples (um único arquivo `index.html`) para organizar posts, stories, roteiros e todo o material do curso para advogados. Sem login, sem servidor — os dados ficam salvos no navegador (localStorage), com botões de **Exportar/Importar backup** no topo.

## Publicar no GitHub Pages (sem precisar de Git)

1. Acesse github.com e clique em **New repository** (repositório novo). Dê um nome, ex: `central-conteudo`, marque como público, e clique em **Create repository**.
2. Na página do repositório recém-criado, clique em **uploading an existing file** (ou "Add file" → "Upload files").
3. Arraste o arquivo `index.html` desta pasta para a janela do navegador e clique em **Commit changes**.
4. Vá em **Settings → Pages** do repositório.
5. Em "Source", selecione a branch `main` e a pasta `/ (root)`, e salve.
6. Em alguns minutos o site fica disponível em `https://<seu-usuario>.github.io/<nome-do-repositorio>/`.

## Backup

Como não tem login nem nuvem, os dados ficam só no navegador que você estiver usando. Use os botões "Exportar backup" e "Importar backup" no site para não perder nada.
